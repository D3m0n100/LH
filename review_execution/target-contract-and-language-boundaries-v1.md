# 目标契约和语言边界 v1

本记录是源码与历史样例的证据冻结，不是控制器验收结果。可复核数据在 `lh-target-observed-contract-v1.json`，140 项目录能力在 `function-block-capability-matrix-v1.json`。未执行编译、测试或下载。

当前生成器 `codegen.py` / `memory.py` / `emitter.py` 可以证明自身行为：System 使用 101，Task 定义 751，FilterBW 定义 851；变量线性分配，INT 大小 2、REAL 大小 4；REAL 即时数编码为 float32 位模式。不能仅由这些行为确认控制器指令表、字节/字地址单位、对齐、字节序或版本支持。emitter 自行累加字段宽度，而 registry 的 offset 是另一套数据，尚未形成一致运行时布局。

LM `程序.zip` 的 SEHC.rep 第 15 行两遍扫描错误数均为 0。SEHC.code 第 79 行 Task 是 `40967 40967 307 8 0 0 8`，第 120 行 FilterBW 是 `41148 41148 543 473`；typ 第 550–553 行列出 BucketDig 的四个字段。fixture 保留源调用、list、typ、code 的摘录、归档条目和 SHA256。307/543/473 是该 LM 样例的绝对地址，不可作为 LH 默认值；40967/751 和 41148/851 之间没有已证实的转换规则。

后端目前把参数当常量编码。VariableRef/MemberRef 操作数类别、初始化/赋值写回、IQ 缩放以及 Task 的调度协议尚无确认的 LH 固件契约。这些功能不能依靠“参数整数恰好等于地址”、新分配常量块、无条件执行分支或展开循环来模拟。生产实现需要目标/固件版本及对应契约；离线 fixture 只能验收模型本身。现有 incomplete 拒绝和没有 Profile 时 compileOnly 的边界继续保留。

| 语言项 | 语法/AST | 后端边界 |
|---|---|---|
| BOOL/整数/REAL | 可解析并保留类型 | 当前生成器有常量编码，硬件 ABI 仍待确认；不等同已完成变量写回 |
| LREAL | 可解析 | 明确拒绝：没有 double 编码契约，不能按 float32 静默缩窄 |
| STRING | 可解析 | 拒绝字符串变量及字符串字面量操作；长度/编码/存储另需契约 |
| TIME/DATE/DT/TOD | 可解析 | 拒绝生成控制代码；单位、纪元、时区、宽度另需契约 |
| POINTER | 语法存在 | 拒绝；地址宽度、引用生命周期和寻址另需契约 |
| ARRAY | 可解析 | 拒绝；布局/下标寻址未完成 |
| VAR_CONSTANT | AST 保留 read_only | 要求初始值；禁止后续赋值和常量功能块实例；初始化写回仍属于 T03 的目标契约工作 |

注册表 `supported` 只描述现有本地定义状态。105 个空参数定义暂按“仅接受无参调用、完整功能契约未核实”分类；没有证据把它们统一认定为合法无实例操作，也没有在本次审计中一次实现或禁用全部 105 项。21 个 incomplete 保留缺失原因并禁止 UI 插入。工程级 Snippet 可以替换模板展示，但不得提升内置编译能力状态。候选无实例操作须另有明确契约，不能因为名字含 End/Lock 就免除内存或参数验证。

外部验收条件：LH 固件版本对应指令/操作数支持表、地址单位和对齐、初始化及写回指令、引用/字段布局、Task/事件协议。功能测试与真实控制器验收由总控单独执行。
