3、两位继电控制 
¾ 功能描述： 
完成一次两位继电控制的计算 
¾ 数学模型 
PosiOut=1, NegOut=0 ( Input≥A1 ,PosiOut=0 ,NegOut=0 ) 
PosiOut=0, NegOut=0 ( Input＜A0 ,PosiOut=1 ,NegOut=0 ) 
PosiOut=0, NegOut=1 ( Input≤-A1 ,PosiOut=0 ,NegOut=0 ) 
PosiOut=0, NegOut=0 ( Input＞-A0 ,PosiOut=0 ,NegOut=1 )
