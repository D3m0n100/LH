# 通用工程设计表与场景清单

这些是配置/设计范例，不能直接执行。以 LH 现有工程编辑、参数、监控和导出组织实施；设备专用算法、调度、IO、持久化、屏烧录和现场验证仍需已核实的目标契约。

## 六类设计表

| 表 | 每行必须记录 |
|---|---|
| 过程 | 工况/阶段、输入、输出、安全值、进入/退出条件、责任人、验收条件 |
| IO | 唯一通道、类型/单位、量程、采样周期、异常值处理、地址/版本证据 |
| 功能 | 输入/输出契约、算法、容差、限幅、除零/超时/故障处理、软件和目标验证 |
| 参数 | 稳定英文 ID、类型、默认/当前、上下限、单位、权限、项目/目标保存策略 |
| 任务 | 周期或事件、前置条件、状态变化、终止/取消、锁/重入约束、目标证据 |
| 文件 | 入口/辅助文件、单一职责、接口、依赖、版本/变更、回归输出路径 |

命名使用有意义的英文及稳定 ID，区分原始值和工程单位。结构上分开初始化、配置与周期执行，保留清晰边界、缩进和注释。审查每个 CASE 的默认分支、循环终止条件、浮点容差、类型转换、启动初始化、任务互斥和重入。

变更表：日期｜版本｜问题 ID｜触发条件｜修改及原因｜验证用例｜结果/限制｜作者/复核人。审查表：缺陷 ID｜需求来源｜软件/目标边界｜严重度｜负责人｜修复证据｜独立复测｜关闭条件。失败不得标为通过，本地通过不得代替现场验收。

## 场景设计例

| 场景 | 通用状态/参数设计 | 关键验收边界 | 本轮可用软件 | 目标延期项 |
|---|---|---|---|---|
| 灯/蜂鸣器、开机屏蔽 | 启动时间、报警条件、许可输出分离 | 8 秒前/等于/之后，断线和复位 | 参数校验、监控、日志 | 目标时钟、物理输出 |
| 16 项保养提示 | 分项阈值、累计量、确认状态、页面选择 | 首/末项、超期、重复确认 | 项目参数快照、表格、历史 | 永久计时、屏、蜂鸣器 |
| 档位/转速自动标定 | 采样窗口、有效样本、标定结果、退出条件 | 空样本、噪声、极值、取消 | 配置、参数和导出 | 传感器/实时标定算法 |
| 泵/发动机及功率模式 | 需求、限值、模式、许可分离 | 切换、过载、无效反馈 | 工程配置、曲线与历史 | 复合控制算法、功率验证 |
| 合流、优先、阻尼 | 工况状态、互斥条件、输出约束 | 冲突、停止、故障降级 | 六类设计表和参数约束 | 阀输出、目标调度 |
| 增压、行走速度 | 请求、许可、最大持续时间、高低速状态 | 最长 8 秒、重复触发、复位 | 参数校验及监控 | 目标定时和机电验证 |
| 功率保护、怠速/升速 | 请求、延时、反馈、保护分离 | 负载突变、超时、复位 | 配置、监控和历史 | 执行算法、执行器 |
| 两小时流程、累计工时 | 单调时间、累计量、恢复点 | 时间回拨、掉电、重复启动 | 审查清单及日志约定 | 目标时钟及持久化 |
| 显示资源/防花屏、局部重建 | 资源清单、版本、校验、重建记录 | 缺图、断线、重复初始化 | 工程文件和清单组织 | 烧录、屏协议、串口/CAN 复位 |

QEP、PWM、电机、按键/屏、PID/TSO、自整定、两位控制和现场 OPC/DCOM 的实际行为须另外验证。配置例不提升功能目录的能力状态。
